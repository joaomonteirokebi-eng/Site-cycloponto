# Site Cycloponto

Landing page de aluguel de bicicletas da Cycloponto Recreio, voltada para turistas.
Passeios: Recreio → Píer da Barra, Recreio → Prainha e Recreio → Grumari.

Site estático (HTML + CSS + JS), sem build: abra `index.html` no navegador ou publique a pasta em qualquer hospedagem estática (GitHub Pages, Netlify, Vercel).

## Ajustes rápidos

- **Número do WhatsApp:** `js/main.js` → `WHATSAPP_NUMBER` (só dígitos, com 55 + DDD).
- **Mensagens pré-preenchidas:** atributo `data-wa` de cada botão no `index.html`.
- **Cores e fontes da marca:** variáveis no topo de `css/styles.css` (`:root`).
- **Logo:** troque o bloco `.brand__mark` no cabeçalho do `index.html` por `<img src="img/logo.svg" alt="Cycloponto">`.
